# ADR-0007: Offline deterministic mock LLM provider

**Status:** Accepted

## Decision
`MockLLMProvider` produces deterministic, structured responses (plans, tool calls, reviews, reports)
so the full workflow runs in local dev, CI and demos without credentials or cost. Every artifact
produced by it is labeled *"Generated by the offline mock model"*, and the UI shows the active provider.
It is never selected silently in production: organizations see a banner until they configure a provider.

## Consequences
+ End-to-end and workflow tests are deterministic and free.
- Mock output demonstrates mechanics, not real intelligence; real quality requires a configured provider.
